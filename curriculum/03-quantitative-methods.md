# الوحدة 03 — الأساليب الكمية والإحصاء التطبيقي
## Quantitative Methods for Market Analysis

> **الصعوبة:** متقدم جداً | **الزمن التقديري:** 16 ساعة | **السابق:** جبر، احتمالات، أساس برمجة
> **الغرض:** تحويل الفرضيات السوقية إلى **مقادير قابلة للاختبار**، ومعرفة **متى يكون الرقم الرياضي صحيحاً حسابياً وكاذباً استدلالياً**.
> **قاعدة الوحدة:** لا نموذج بلا شروط صحة معلنة، ولا نتيجة بلا فاصل ثقة، ولا إشارة بلا معيار تكاليف.

## القسم الأول — قانون التحقق أولاً (المادة 4.1)

قبل أي إحصاء، تُثبَّت شروط قبول النتيجة. النتيجة التي لا تستوفي هذه الشروط **مرفوضة بغض النظر عن جمالها**:

1. **اختبار خارج العينة (Out-of-Sample):** التقسيم الزمني وليس العشوائي. التقسيم العشوائي على سلاسل زمنية = تسريب بيانات (المادة 8.3).
2. **نموذج تكاليف واقعي:** `Total_Cost = Spread + Fees + Slippage + Gas + Funding + Bridge`.
3. **تحليل قدرة (Capacity):** السعة القصوى محكومة بسقف المشاركة 5% (المادة 5.3):
```
Capacity_Notional = ADV_market × 0.05
```
4. **فحص فرط التوفيق (Overfitting):** عدد المحاولات نفسه **بيانات إلزامية**.

**نسبة شارب المُفرَّغة (Deflated Sharpe Ratio):**
```
SR_0 = √Var(SR_n) · [ (1−γ)·Φ⁻¹(1 − 1/N) + γ·Φ⁻¹(1 − 1/(N·e)) ]
DSR  = Φ( (SR_hat − SR_0)·√(T−1) / √(1 − γ3·SR_hat + ((γ4 − 1)/4)·SR_hat²) )
```
حيث `N` عدد المحاولات المستقلة، `γ` ثابت أويلر–ماسكيروني، `γ3` الالتواء، `γ4` التفرطح، `T` عدد المشاهدات، `Φ` دالة التوزيع الطبيعي المعياري. **المعنى:** شارب مرتفع بعد 2000 محاولة قد لا يكون معنوياً إطلاقاً.
**وأضف ضابط الدستور:** أي نتيجة تتجاوز **3×** المعيار المرجعي تُصنَّف مشتبهاً بها حتى تُثبت العكس (المادة 4.2).

**مانع التسريب (Purging & Embargo):** في التحقق المتقاطع الزمني، تُحذف فترة «تنقية» حول حدود الطيّات وفترة «حظر» بعدها، لأن الأفق الزمني للصفقة يجعل مشاهدات التدريب تحتوي معلومة الاختبار.

**متى تفشل هذه الضوابط:** (أ) `Var(SR_n)` قد تكون مجهولة فتُقدَّر تقديراً متفائلاً؛ (ب) افتراض استقلال المحاولات يسقط عند تعديل نفس الاستراتيجية بمكرر؛ (ج) ضوابط Overfitting **تُخفض** الأداء المُعلن دائماً — ومن يرفضها فهو يختار رقماً لا حقيقة.

## القسم الثاني — الإحصاء الأساسي والتقلب

### 2.1 العزوم والتوزيعات

```
Mean      μ = E[X]
Variance  σ² = E[(X−μ)²]
Skewness  γ3 = E[(X−μ)³] / σ³
Kurtosis  γ4 = E[(X−μ)⁴] / σ⁴        (Excess = γ4 − 3)
```
**اختبار جارك–بيرا (Jarque–Bera):** `JB = (T/6)(γ3² + (γ4−3)²/4) ~ χ²(2)`.

**التوزيعات الثلاثة التي يعمل بها الديسك:**
- **الطبيعي (Normal):** مرجعي فقط، **لا يُستخدم للتقدير المخاطري** على عوائد الأصول الرقمية.
- **t-Student:** أذيل سميكة؛ تُستخدم بتقدير درجات حرية `ν`؛ تتقارب للطبيعي عند `ν → ∞`. عادةً `ν` صغير في السلاسل يومية عالية التقلب.
- **التوزيع اللوغاريتمي الطبيعي (Lognormal):** ملائم لمستويات السعر لا للعوائد اللحظية.

### 2.2 الأذيل السميكة (Fat Tails)

```
قانون القوة:  P(|X| > x) ~ C · x^(−α)   , x → ∞
مقدّر هيل:    α̂ = 1 / [ (1/k) Σ_{i=1..k} ln( X_(i) / X_(k+1) ) ]
```
حيث `X_(i)` الإحصاءات الرتبية للقيم المتطرفة. كلما صغر `α̂` كانت الذيلية أثقل.

**الأثر العملي:** أي تقدير مخاطري بتوزيع طبيعي على سلسلة `α̂` صغير **يُقلّل احتمال الخسارة الفادحة بنيوياً**. هذه ليست ملاحظة نظرية بل سبب مباشر لتجاوز حدّ 15% للتراجع (المادة 5.3).

### 2.3 التقلب المتحقق (Realized Volatility) والمقدّرات البديلة

```
RV_t = √( Σ_{i=1..n} r_{t,i}² )
Parkinson   : σ̂² = (1/(4 ln2)) · [ln(H/L)]²
Garman–Klass: σ̂² = 0.5[ln(H/L)]² − (2ln2 − 1)[ln(C/O)]²
```
التمييز إلزامي: **التقلب التاريخي (Historical)** على نافذة، **التقلب المتحقق (Realized)** من بيانات عالية التردد، **التقلب الضمني (Implied)** من أسواق المشتقات. الثلاثة تُقيس أشياء مختلفة، والخلط بينها خطأ منهجي شائع.

### 2.4 نماذج GARCH

**GARCH(1,1):**
```
σ²_t = ω + α·ε²_{t−1} + β·σ²_{t−1}
Persistence = α + β            (قريب من 1 يعني ذاكرة تقلب طويلة)
Long-run Var = ω / (1 − α − β)
Forecast(h)  = σ²_∞ + (α+β)^{h−1}·(σ²_{t+1} − σ²_∞)
```
**عدم التماثل (Leverage Effect):** تميل الصدمات السالبة لتزيد التقلب أكثر. صيغة GJR:
```
σ²_t = ω + α·ε²_{t−1} + γ·ε²_{t−1}·1{ε_{t−1}<0} + β·σ²_{t−1}
```
**متى تفشل GARCH:** (أ) تفترض استمرارية البنية، وتنكسر عند ترقيات الشبكة أو أحداث الجسور؛ (ب) بطيئة في التقاط انفجار التقلب الفوري؛ (ج) لا تعطي ذيلية صحيحة للخسائر المفردة؛ (د) تقدير `ω, α, β` على نوافذ قصيرة غير مستقر.

## القسم الثالث — السلاسل الزمنية

### 3.1 السكون (Stationarity) وجذر الوحدة

سلسلة **ساكنة** إذا كانت `E[X_t]` و`Var(X_t)` ثابتتين والارتباط الذاتي يعتمد على الفارق فقط. **السير العشوائي (Random Walk)** غير ساكن:
```
X_t = X_{t−1} + ε_t    ,  Var(X_t) = t·σ²   → يتفجر مع الزمن
```
**الانحدار الكاذب (Spurious Regression):** انحدار سلسلتين مستقلتين غير ساكنتين يُنتج `R²` مرتفعاً و`t` معنوياً بلا أي علاقة حقيقية. **هذا أخطر فخ في الوحدة**: كل انحدار سعري بلا اختبار سكون = نتيجة مشكوكة افتراضياً.

### 3.2 اختبار ديكي–فولر الموسّع (ADF)

```
Δy_t = α + β·t + γ·y_{t−1} + Σ_{i=1..p} δ_i·Δy_{t−i} + ε_t
H0 : γ = 0   (جذر وحدة ⇒ غير ساكنة)
```
الرفض (إحصاء أكثر سلباً من القيمة الحرجة) يدعم السكون. اختيار `p` بمعيار AIC/BIC. **حدوده:** قدرة منخفضة على كسر بنيوي (Structural Break) — يُظهر «سكوناً» كاذباً إذا كان الكسر قوياً؛ وكثيراً ما يخلط السكون حول اتجاه حتمي بالسكون التام.

### 3.3 ARIMA وACF/PACF

```
AR(p)   : y_t = c + Σ φ_i y_{t−i} + ε_t
MA(q)   : y_t = c + ε_t + Σ θ_j ε_{t−j}
ARIMA   : فرق d مرة ثم ARMA(p,q)
Ljung–Box : Q = T(T+2) Σ_{k=1..m} ρ̂_k²/(T−k)  ~ χ²(m−p−q)
```
**قاعدة القراءة:** ACF تتلاشى تدريجياً وPACF تُقطع عند `p` ⇒ AR؛ العكس ⇒ MA؛ تلاشٍ تدريجي في الاثنتين ⇒ فرق (d).

### 3.4 التكامل المشترك (Cointegration)

**إنجل–غرانجر (خطوتان):** (1) قدّر `y_t = β x_t + u_t` بـ OLS؛ (2) اختبر سكون `û_t` بـ ADF. سكون البواقي = تكامل مشترك. **الحد:** يفترض اتجاهاً واحداً للسببية ويفشل عند وجود أكثر من علاقة.

**يوهانسن (اختبار الأثر):**
```
LR_trace(r) = −T · Σ_{i=r+1..k} ln(1 − λ̂_i)
```
حيث `λ̂_i` القيم الذاتية المرتبة تنازلياً من تقدير VECM. يعطي عدد متجهات التكامل المشترك `r`.

**متى تفشل:** (أ) التكامل المشترك **علاقة قابلة للكسر**: حدث شبكي أو تغيير عرض نقدي يُنهيها؛ (ب) التقدير على العينة كاملة يُنتج معاملات لا تنطبق على العينة الفرعية؛ (ج) في الأسواق الرقمية تزول العلاقات عند تغيّر الحوافز (انتهاء برنامج مكافآت).

### 3.5 نصف العمر وعملية أورنشتاين–أولنبك

```
Continuous : dX_t = θ(μ − X_t) dt + σ dW_t
Discrete   : ΔS_t = λ·S_{t−1} + c + ε_t     , λ = −(1 − e^{−θΔt})
Half-Life  : t_{1/2} = ln(2) / θ = − [ ln(2) / ln(1 + λ) ] × Δt        (زمن تقويمي)
             n_{1/2} = t_{1/2} / Δt = − ln(2) / ln(1 + λ) = ln(2) / (θ·Δt)   (عدد الفترات)
Stationary Var = σ² / (2θ)
```
> **تصحيح موثّق (تدقيق):** كان النص يساوي بين `ln(2)/θ` و`−ln(2)/ln(1 + λ)` بلا `Δt`، وهو **إسقاط للوحدة الزمنية**. بما أن `1 + λ = e^{−θΔt}`، فإن `−ln(2)/ln(1 + λ) = ln(2)/(θ·Δt)`، وهو نصف العمر **بعدد الفترات** لا بالزمن؛ ولا يتساويان إلا عند `Δt = 1`. الصيغة المصحّحة تضرب في `Δt` للتحويل إلى زمن تقويمي، وتُبقي `n_{1/2}` بصيغة عدد الفترات. مثال: `λ̂ = −0.05` على بيانات **أسبوعية** (`Δt = 7` أيام) يعطي `n_{1/2} = 13.51` أسبوعاً، أي `t_{1/2} = 94.6` يوماً — لا 13.5 يوماً.

**التطبيق:** نصف العمر هو **الأفق الأقصى المعقول** لاستراتيجية ارتداد للمتوسط. إشارة نصف عمرها 40 يوماً لا تُتداول بأفق ساعات — هذا تناقض بنيوي وليس تفصيلاً.

**متى يفشل:** `θ` المقدَّر غير ثابت زمنياً؛ وعند `θ→0` يتفجر نصف العمر؛ والتقدير حساس للقيم المتطرفة ولطول النافذة.

## القسم الرابع — بناء الإشارات

### 4.1 الدرجة المعيارية (Z-Score)

```
z_t = (x_t − μ̂_{t−n:t}) / σ̂_{t−n:t}
Entry : |z_t| ≥ 2   |   Exit : |z_t| ≤ 0.5   |   Stop : |z_t| ≥ 3.5
```
**شرط صحة:** `x_t` مستقر أو فرق-مستقر. حساب `z` على سلسلة غير ساكنة يُنتج إشارات «تطبيع» وهمية هي في الحقيقة اتجاهات.
**حدوده:** `σ̂` التقديري متأخر (انفجار التقلب يرفع `z` بعد فوات الأوان)، والتوزيع السميك يجعل `|z|>2` أكثر شيوعاً من المتوقع طبيعياً.

### 4.2 الزخم (Momentum)

```
Cross-sectional : R_{12−1} = P_{t−1M} / P_{t−12M} − 1      (شراء أعلى عشير)
Time-series     : sign(R_{12−1}) مع تحجيم تقلبي:
Position_t = (σ_target / σ̂_t) · sign(R_{12−1})
```
**متى يفشل:** (أ) انقلاب الزخم بعد الصدمات (Momentum Crash) — التوزيع شديد الالتواء السالب؛ (ب) التكاليف تستهلك الإشارة عند تقلب دوران مرتفع؛ (ج) في الأسواق الرقمية، إشارة الزخم على أصول صغيرة تتشبع بسبب سقف المشاركة 5%.

### 4.3 الارتداد للمتوسط (Mean Reversion)

يُبنى على زوج متكامل أو على انحراف عن قيمة مرجعية، مع **قيد نصف العمر**:
```
Signal = −z_t · 1{ t_{1/2} < Horizon_target }
```
**متى يفشل:** يستقبل أسوأ ما في العالمين: تنفيذ على انحراف لا يعود (اتجاه)، وتكلفة عالية مع تكرار عالٍ للصفقات.

### 4.4 مرشّح كالمان (Kalman Filter)

**الصيغة الحالية (State-Space):**
```
State   : x_t = F x_{t−1} + w_t ,   w ~ N(0, Q)
Observe : z_t = H x_t + v_t     ,   v ~ N(0, R)

Predict : x̂_{t|t−1} = F x̂_{t−1|t−1} ;  P_{t|t−1} = F P_{t−1|t−1} Fᵀ + Q
Update  : K_t = P_{t|t−1} Hᵀ (H P_{t|t−1} Hᵀ + R)^{−1}
          x̂_{t|t} = x̂_{t|t−1} + K_t (z_t − H x̂_{t|t−1})
          P_{t|t} = (I − K_t H) P_{t|t−1}
```
**التطبيقان الأهم:** (1) تقدير نسبة التحوّط `β_t` المتغيّرة زمنياً في زوج تحكيمي؛ (2) استخراج **متوسط متحرك متكيّف** بدل متوسط بسيط.

**متى يفشل:** (أ) `Q` و`R` مجهولتان عملياً، وتقديرهما يحدد السلوك أكثر من البيانات؛ (ب) يفترض خطية وغاوسية، فتنكسر عند قفزات السعر؛ (ج) قد يتقارب ببطء بعد كسر بنيوي فيبدو «متحركاً» وهو متأخر.

## القسم الخامس — بناء المحفظة والعوامل

### 5.1 تحليل المكوّنات الرئيسية (PCA)

```
Σ = V Λ Vᵀ   ,  Λ = diag(λ_1 ≥ λ_2 ≥ … ≥ λ_n)
Variance_Explained_k = Σ_{i≤k} λ_i / Σ_i λ_i
Score_t = V_kᵀ · r_t
```
**الاستخدامات:** تقليل الأبعاد قبل تقدير التباين؛ كشف العامل المهيمن (عادةً «السوق» في الأصول الرقمية)؛ بناء مراكز محايدة تجاه العامل الأول.
**الحدود:** المكوّنات **غير ثابتة** زمنياً؛ وتفسيرها الاقتصادي غالباً لاحق للنتيجة (Narrative Fitting).

### 5.2 نماذج العوامل والتباين

```
r = B f + ε
Σ_r = B Σ_f Bᵀ + Ψ            (Ψ = diag تباين خاص)
Risk_Contribution_i = w_i · (Σ_r w)_i / (wᵀ Σ_r w)
```
وهذا هو المقياس الصحيح لـ«حجم المخاطرة»، لا الوزن الاسمي: مركز 5% في أصل مرتبط بكل شيء قد يساهم بمخاطرة أكبر من مركز 10% في أصل منعزل. **وهو ما يفسّر حدّ التركّز القطاعي 25%** (المادة 5.3).

### 5.3 تقليص مصفوفة التباين (Ledoit–Wolf Shrinkage)

مصفوفة التباين المُقدَّرة من `n` أصلاً و`T` مشاهدة تكون **شاذة/سيئة الشرط** عند `n` قريب من `T`:
```
Σ_LW = δ · F + (1 − δ) · S
δ* = argmin_δ E‖ δ F + (1−δ) S − Σ_true ‖²
```
حيث `F` هدف منخفض البُعد (مثل مصفوفة ارتباط ثابت)، و`S` المصفوفة العينية. **الحد:** التقليص يقلّل خطر التقدير ويُدخل انحيازاً؛ واختيار `F` قرار نمذجي لا محايد.

### 5.4 المحافظ المثلى مع قيود الدستور

```
Min-Variance : w* = Σ⁻¹1 / (1ᵀ Σ⁻¹ 1)
Max-Sharpe   : w* ∝ Σ⁻¹ μ
مع القيود   : 0 ≤ w_i ≤ 0.10   ,   Σ_{i∈sector} w_i ≤ 0.25   ,   Σ w_i ≤ 1
```
**الحقيقة المزعجة:** خطأ تقدير `μ` يهيمن على خطأ تقدير `Σ` بمراتب؛ لذلك المحافظ المبنية على `μ` المُقدَّر هشّة. **الإجراء:** تقليص `μ` (Shrinkage) وتفضيل قيود صلبة.

## القسم السادس — المحاكاة

### 6.1 مونت كارلو

**الحركة البراونية الهندسية (GBM):**
```
S_{t+Δ} = S_t · exp[ (μ − σ²/2)Δ + σ√Δ · Z ]   ,  Z ~ N(0,1)
```
**خفض التباين:** المتغيّرات المتضادة (Antithetic) `Z` و`−Z`؛ وأخذ العينات الأهمية (Importance Sampling) لأحداث الذيل.
**عدد المسارات:** الخطأ المعياري للمقدّر يتناقص بـ `1/√M` — أي أن مضاعفة الدقة تحتاج **أربعة أضعاف** المسارات.

### 6.2 التحميل الذاتي (Bootstrap)

```
Resample iid : {r*_1..r*_T} ~ Uniform({r_1..r_T})
SE_boot = √( (1/(B−1)) Σ_{b=1..B} ( θ̂*_b − θ̄* )² )
```
**الحد:** يفترض استقلال المشاهدات — وهو **كاذب** في العوائد المالية (تجمّع تقلب، ارتباط ذاتي، ذيول).

### 6.3 تحميل الكتل (Block Bootstrap)

**الكتل المتحركة (Moving Block):** تُسحب كتل متتالية طولها `ℓ` بدل مفردات:
```
عدد الكتل  m = ⌈T / ℓ⌉
اختيار ℓ  ≈ T^{1/3}   أو من مدى الاعتماد الذاتي المقاس
```
**Block Bootstrap البطيء (Stationary Bootstrap):** طول كتلة عشوائي هندسي بمتوسط `ℓ` — يحافظ على السكون.
**الأثر:** يحفظ البنية المحلية (تجمّع التقلب)، ويعطي فواصل ثقة **أوسع وأصدق** من iid.
**الحد:** `ℓ` تُختار تقديراً، والنتيجة حساسة لها؛ ولا يحفظ الاعتماد الطويل المدى ولا الكسور البنيوية.

### 6.4 الاعتماد على المسار (Path Dependency)

توزيع النتيجة النهائية **لا يكفي** لأي قرار بحدّ خسارة أو إيقاف. المطلوب توزيع **المسارات**:
```
Max_DD_b = max_t [ (Peak_{b,t} − W_{b,t}) / Peak_{b,t} ]
P(Max_DD > 0.15) = (1/B) Σ_b 1{Max_DD_b > 0.15}          (حدّ المادة 5.3)
P(Touch_Daily_Loss_2%) = (1/B) Σ_b 1{ max_daily_loss_b ≥ 0.02 }
```
**مبدأ إلزامي:** أي استراتيجية تُقيَّم أولاً باحتمال لمس حدود الإيقاف، وثانياً بالعائد. من يقيس العائد أولاً يخالف المادة 5.2.

**متى تفشل المحاكاة:** (أ) **خطر النموذج (Model Risk):** المحاكاة تُنتج ما يفترضه النموذج؛ GBM لا يُنتج فجوات ولا أذيلاً سميكة؛ (ب) معاملات مُقدَّرة على فترات هادئة تُخفي الأزمات؛ (ج) الارتباط يُفترض ثابتاً بينما ينهار في الأزمات (الوحدة 04).

## معيار إتمام الوحدة 03

1. **كل التمارين الثمانية** منفَّذة بكود أو بخطوات حسابية كاملة قابلة للتكرار.
2. **إعادة إنتاج رقمية** لمعادلات الوحدة: GARCH، ADF، نصف العمر، كالمان، DSR.
3. **شرط صحة معلن** لكل نموذج استُخدم، وإلا عُدّ الاستخدام باطلاً.
4. **فاصل ثقة** على كل تقدير نقطي مُقدَّم (لا رقم مفرد بلا عدم يقين).
5. **تحليل قدرة** لكل إشارة مقترحة بسقف 5%، مع إقرار صريح بتدهور الإشارة عند الاقتراب من السقف.
6. **توثيق عدد المحاولات** `N` لكل نتيجة شارپ مُعلنة.
7. **عتبة الاجتياز: انظر `exams/README.md §2` (تختلف بحسب الوكيل)** + المرحلة الانضباطية، مع إلزامية الامتناع حيث لا تكفي البيانات.
