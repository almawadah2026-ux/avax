> **الصعوبة:** متقدم | **الزمن التقديري:** 12 ساعة | **السابق:** الوحدة 03 (جزئياً)
> **المبدأ الحاكم:** المخاطر تُقاس قبل الربح (المادة 5.2)، وأي قرار بلا **أقصى خسارة مقبولة** مرفوض آلياً.

## القسم الأول — تصنيف المخاطر

| نوع المخاطرة | التعريف | كيف تُقاس | تمثيلها على أفالانش | التخفيف |
|---|---|---|---|---|
| **سوقية (Market)** | تغيّر السعر ضد المركز | `σ`, `β`, `VaR`, `ES` | تقلب AVAX المرتفع في نوافذ الأحداث | تحجيم المركز، تحوّط، أفق قصير |
| **سيولة (Liquidity)** | استحالة الخروج بسعر قريب من السعر العادل | سبريد + أثر سعري + زمن التصفية | عمق منخفض في صناديق LFJ لبعض الأزواج | سقف مشاركة 5%، تقسيم زمني للخروج |
| **طرف مقابل (Counterparty)** | فشل الطرف الآخر عن الوفاء | تعرّض مُقاس بمبلغ محجوز | جسر بوصاية، منصة مركزية، مُصدر عملة مستقرة | توزيع، حدود لكل طرف، مراقبة الضمانات |
| **تشغيلية (Operational)** | خطأ بشري/نظامي/مفتاح | تكرار الحوادث، زمن الاستعادة | خطأ شبكة أو RPC أو إعداد محفظة | فصل المفاتيح، اختبارات، نسخ احتياطي |
| **تنظيمية (Regulatory)** | تغيّر قواعد يغيّر الجدوى | سيناريوهات سياسة | تصنيف الرموز، قواعد الإدراج، الضرائب | متابعة، تخفيف تعرّض، امتناع |
| **النماذج (Model Risk)** | أن يكون النموذج خاطئاً لا أن تكون البيانات خاطئة | اختبار خارج العينة، فحص كسر بنيوي | GARCH مُقدَّر قبل ترقية تغيّر بنية الرسوم | عيّنات فرعية، اختبارات ضغط، احتياط |

**قاعدة الفصل:** مخاطر السيولة وطرف المقابل **لا تظهر في `σ`** ولا في `VaR` المعياري. لذلك أي قياس مخاطري لا يذكرها هو قياس ناقص بنيوياً.

## القسم الثاني — معيار كيلي: الاشتقاق الكامل

### 2.1 الإطار

رهان متكرر: ربح بمقدار `b` لكل وحدة مراهنة مع احتمال `p`، وخسارة الوحدة كاملة مع احتمال `q = 1 − p`. يُراهَن بكسر ثابت `f` من الثروة الحالية:

```
W_t = W_0 · (1 + b f)^{N_w} · (1 − f)^{N_l}      , N_w + N_l = t
```
حيث `W_t` الثروة بعد `t` رهاناً، و`N_w` عدد المكاسب، و`N_l` عدد الخسائر، و`f` الكسر الثابت من الثروة، و`b` الربح لكل وحدة مراهنة.

> **تصحيح موثّق (تدقيق):** كانت الصيغة `W_n = W_0 · (1 + b f)^{W} · (1 − f)^{L}` تستخدم الرمز `W` **مرتين بمعنيين متعارضين**: ثروةً (`W_n`, `W_0`) وعددَ مكاسب في الأُس. فُصل الرمزان: الثروة `W_t` (و`W_0` ثروة البداية)، وعدد المكاسب `N_w`، وعدد الخسائر `N_l`، مع `N_w + N_l = t`. أي خلط بينهما يُفسد الأُس ويُبطل أي استنتاج لاحق عن النمو اللوغاريتمي `g(f)`.

### 2.2 تعظيم النمو اللوغاريتمي

معدل النمو لكل رهان:
```
g(f) = p · ln(1 + b f) + q · ln(1 − f)
```
شرط الرتبة الأولى:
```
dg/df = p·b/(1 + b f) − q/(1 − f) = 0
⇒ p b (1 − f) = q (1 + b f)
⇒ f* = (p b − q) / b = p − q/b
```
شرط الرتبة الثانية (تأكيد القمة):
```
d²g/df² = − p b²/(1+bf)² − q/(1−f)²  < 0     لكل f ∈ (0,1)
```
**حالات خاصة:**
```
احتمال متساوٍ (b = 1) : f* = 2p − 1
صيغة الاستمرار        : f* ≈ μ / σ²      (μ عائد فائض، σ² تباين)
متعدد الأصول          : f* = Σ⁻¹ (μ − r)
```

### 2.3 نصف كيلي: لماذا هو قاعدة الدستور (المادة 5.5)؟

مع `f = c · f*` في الصيغة المستمرة:
```
g(c f*) = c f* μ − (c f*)² σ²/2 = (2c − c²) · g(f*)
```
| `c` | النمو المحتفظ به | ملاحظة |
|---|---|---|
| 1.00 (كيلي كامل) | 100% | أقصى نمو، أقصى تقلب، أخطر تقدير |
| **0.50 (نصف كيلي)** | **75%** | خسارة 25% من النمو مقابل خفض كبير في خطر الإفلاس |
| 0.25 | 43.75% | تحفظ شديد |

**النتيجة:** نصف كيلي يخسر ربع النمو فقط، وهو ثمن رخيص مقابل ما يُشترى به (القسم التالي).

**حدود كيلي وأخطاؤه:**
1. **`p` مجهولة.** الخطأ في `p` يُضخَّم خطياً في `f*`، والمراهنة الزائدة عن `f*` تُخفّض النمو **وقد تُصفّره**.
2. **اللامرجعية (Non-Ergodicity):** كيلي يعظّم النمو المتوقع، لكن المسار الفردي لا يرى المتوسط؛ متوسط الزمن ≠ متوسط التجمعات.
3. **الرهانات المتزامنة المرتبطة** تُقلّل الحافة الفعلية، فكيلي أحادي الأصل يُبالغ في الحجم.
4. **الكسر غير قابل للتجزئة** عملياً (حد أدنى للحجم، رسوم، غاز).

**مثال توضيحي (أرقام تعليمية لا سوقية):** بفرض `p = 0.55`, `b = 1`: `f* = 0.10`. فيصبح الحد الأقصى المسموح `0.05` (نصف كيلي)، وهو أقل من سقف المركز الواحد 10% (المادة 5.3) — **الأدق يقيّد الأوسع**.

## القسم الثالث — خطر الإفلاس (Risk of Ruin)

### 3.1 الاشتقاق بمعامل التسوية

لتكن `X_i ∈ {+1, −1}` و`f` ثابتاً. نبحث عن `θ ≠ 1` بحيث:
```
E[ (1 + f X)^θ ] = 1
⇒ p (1 + f)^θ + q (1 − f)^θ = 1
```
عندها `M_t = ∏ (1 + f X_i)^θ` مارتنغيل، ومنه:
```
P(ruin) ≈ ( W_barrier / W_0 )^θ
```

### 3.2 التقريب المستمر والعلاقة بكيلي

مع انجراف `m = f μ − f²σ²/2` وتقلب `s = f σ`:
```
R = exp( −2 m D / s² )         ,  D = ln(W_0 / W_barrier)
```
وبتعويض `f = c · f*` حيث `f* = μ/σ²` نحصل على الأُس `2m/s² = 2/c − 1`، أي:
```
R = ( W_barrier / W_0 )^( 2/c − 1 )
c = 1     :  R = (W_b/W_0)^1      →  كيلي كامل
c = 1/2   :  R = (W_b/W_0)^3      →  نصف كيلي
c = 1/4   :  R = (W_b/W_0)^7      →  ربع كيلي
```
**هذه أقوى حجة رياضية في الوحدة:** نصف كيلي **يُكعّب** احتمال الاقتراب من حاجز الإفلاس مقابل خسارة 25% من النمو فقط. لهذا المادة 5.5 ليست تفضيلاً محافظاً بل نتيجة اشتقاقية.

**حدود المعادلة:** تفترض استقلال الرهانات، وثبات `μ, σ`، وعدم وجود قفزات؛ وفي الأسواق الحقيقية توجد **قفزات** (Gaps) تُبطل استمرارية المسار وتجعل الإفلاس أقرب مما تقول المعادلة. لذلك تُقرأ النتيجة كـ **حدّ أدنى للخطر** لا كتقدير.

### 3.3 الكسر الثابت الأمثل (Fixed Fractional — Vince)

```
HPR_i = 1 + f · (R_i / |Worst_Loss|)
TWR(f) = ∏_{i=1..N} HPR_i
Geometric_Mean = TWR(f)^{1/N} − 1
f_opt = argmax_f TWR(f)
```
**الملاحظة الحرجة:** `f_opt` مبني على **أسوأ خسارة تاريخية** — وهو مقياس هشّ: أسوأ خسارة لم تحدث بعد. في المقارنة، `f_opt` غالباً **أكبر** من كيلي، أي أكثر عدوانية. **حكم الديسك:** يستخدم Fixed Fractional **لقياس** المخاطرة، لا **لتحجيم** المراكز.

## القسم الرابع — قياس الخسارة: VaR وCVaR والتراجع

### 4.1 القيمة المعرّضة للخطر (VaR) بثلاث طرق

**الطريقة 1 — معيارية (Parametric):**
```
VaR_c = −W ( μ + σ · Φ⁻¹(1 − c) )
مثال: c = 0.99 ⇒ Φ⁻¹(0.01) = −2.326 ⇒ VaR ≈ 2.326 σ W
```
**الطريقة 2 — محاكاة تاريخية (Historical Simulation):** ترتيب العوائد التاريخية وأخذ المئين المقابل. لا تفترض توزيعاً لكنها **لا ترى ما لم يحدث**.
**الطريقة 3 — مونت كارلو:** توليد توزيع من نموذج، ثم أخذ المئين. جودتها = جودة النموذج لا أكثر.
**تصحيح كورنيش–فيشر للذيلية:**
```
z_CF = z + (z²−1)/6 · γ3 + (z³−3z)/24 · γ4_excess − (2z³−5z)/36 · γ3²
```

**قيود VaR (إلزامية الذكر):**
1. **ليست مقياساً متماسكاً:** قد تخالف **الجمع الجزئي (Subadditivity)** — `VaR(A+B) > VaR(A)+VaR(B)` ممكن، أي أن التنويع قد «يزيد» VaR شكلياً. هذه ليست غرابة رياضية بل خلل تصميمي.
2. **تتجاهل ما بعد المئين** كلياً: خسارة 10% و50% عند نفس المئين لهما نفس VaR.
3. **تقلّب تقديري عالٍ** في الأذيل (نادراً ما تُقدَّر بدقة).
4. **مشوّهة دورياً (Procyclical):** تنخفض في الهدوء وترتفع بعد الصدمة — أي تصل متأخرة.

### 4.2 الخسارة المتوقعة CVaR / ES

```
ES_c = E[ L | L ≥ VaR_c ]
Normal case: ES_c = μ + σ · φ(z_c)/(1 − c)
```
خصائص: **متماسكة (Coherent)** — مُتجانسة موجبة، رتيبة، ثابتة الترجمة، و**متحققة الجمع الجزئي**. لذلك **هي المقياس المعتمد في هذا الديسك** عند التعارض، وVaR يبقى للتواصل فقط.

### 4.3 التراجع والمقاييس المصحّحة بالمخاطرة

```
Drawdown_t   : DD_t = (Peak_t − W_t) / Peak_t
Max Drawdown : MaxDD = max_t DD_t
Ulcer Index  : UI = √( (1/N) Σ_t DD_t² )
Calmar       : Calmar = CAGR / MaxDD      ,  MaxDD كسر موجب ∈ (0, 1] (وإلا انقلبت الإشارة)
Sortino      : Sortino = (R_p − MAR) / DD_dev  ,  DD_dev = √( (1/N) Σ min(0, R_t − MAR)² )
```
> **تصحيح موثّق (تدقيق):** كان `Calmar = CAGR / MaxDD` بلا تنصيص على إشارة `MaxDD`. التعريف أعلاه `DD_t = (Peak_t − W_t)/Peak_t` يعطي **كسراً موجباً**؛ فإذا استُخدم `MaxDD` كرقم سالب (كما تُعرَّفه بعض المصادر كأقصى خسارة سالبة) انقلبت إشارة Calmar وصار الأداء الأسوأ يبدو أفضل. الصيغة تُشترط الآن على أن `MaxDD` **كسر موجب** `∈ (0, 1]`؛ ومعه يكون Calmar موجباً و«الأعلى أفضل» بلا التباس.

**لماذا UI أفضل من MaxDD وحده:** MaxDD قيمة واحدة قابلة للحذف بحذف مسار واحد؛ `UI` يدمج **العمق والمدة**.
**مثال توضيحي:** محفظتان بنفس MaxDD = 15%، الأولى تعافت في أسبوع والثانية في ستة أشهر: `UI` الثانية أعلى بمراتب — وهي في الواقع أخطر.

**حدودها كلها:** كل هذه المقاييس **تاريخية (Backward-Looking)**؛ ولا تقول شيئاً عن سيناريو لم يحدث. لذلك تُستكمل بالضغط (القسم التالي).

## القسم الخامس — اختبارات الضغط والارتباط في الأزمات

### 5.1 أنواع السيناريوهات

| النوع | البناء | الغرض |
|---|---|---|
| **تاريخي** | إعادة تشغيل واقعة فعلية (بمعطياتها وتواريخها) | قياس سلوك حقيقي |
| **افتراضي (Hypothetical)** | صدمة مُصمَّمة (مثلاً `−40%` في 24 ساعة) | استكشاف ما لم يحدث |
| **عكسي (Reverse Stress Test)** | ابحث عن السيناريو الذي **يخرق** حدودنا | تحديد نقطة الانكسار |
| **مشترك (Correlated)** | صدمة على عامل واحد مع ارتفاع الارتباطات | محاكاة العدوى |

**الصيغة الأساسية للضغط:** إعادة تقدير المركز تحت السيناريو، لا تحت التوزيع:
```
P&L_scenario = Σ_i w_i · R_i^{scenario}      (R_i^scenario مفروض لا مُقدَّر)
```

### 5.2 الارتباط في الأزمات

```
ρ_ij^{crisis} > ρ_ij^{calm}     (الارتباط يقفز نحو 1 عند الصدمة)
Tail dependence : λ_U = lim_{u→1} P(U_j > u | U_i > u)
```
**الأثر على الديسك:** التنويع المبني على ارتباطات فترة هادئة **يختفي** وقت الحاجة إليه. وبناءً عليه: حدّ التركّز القطاعي 25% (المادة 5.3) يُقاس على **الارتباط في الأزمة** لا الارتباط اليومي.

**حدود:** الارتباط يلتقط العلاقة الخطية فقط؛ والتوزيعات السميكة تحتاج ارتباطاً رتبياً (Rank/Spearman) أو copula؛ وتقدير `λ_U` من بيانات قليلة شديد عدم الاستقرار.

## القسم السادس — سلّم الإنذار وحدود الديسك

| المستوى | الحالة | الإجراء (المادة 9.3) |
|---|---|---|
| 🟢 أخضر | كل الحدود سليمة | عمل طبيعي |
| 🟡 أصفر | تقلب مرتفع أو بيانات ناقصة | خفض حجم المركز 50% |
| 🟠 برتقالي | خسارة يومية 1.5% | إيقاف المراكز الجديدة |
| 🔴 أحمر | خسارة 2% أو خرق قاعدة | **إيقاف كامل فوري** |

```
خسارة اليوم = ( W_start_of_day − W_now ) / W_start_of_day
عتبة التوقف الآلي = 2%   →   إيقاف بلا نقاش ولا استثناء (المادة 5.4)
```
**حدود ملزمة:** أقصى خسارة يومية 2% | أقصى تراجع 15% | أقصى مركز 10% | أقصى قطاع 25% | أدنى ثقة للدخول 65 | أقصى مشاركة من حجم السوق 5%.

**قاعدة منع الالتفاف:** تقسيم مركز واحد إلى مراكز صغيرة لتجاوز حدّ 10% هو **خرق دستوري** (المادة 8.7)، ويُكشف باختبار التجمع (Clustering Test): مجموع المراكز المترابطة بارتباط أزماتي عالٍ يُحسب **كمركز واحد**.

## القسم السابع — مخاطر الأونشين: المنصة، الجسر، العقد، السحب

### 7.1 قائمة فحص العقد الذكي والرمز (Minimum Viable Due Diligence)

| البند | ما يُفحص | علامة خطر |
|---|---|---|
| صلاحية الإصدار (Mint Authority) | موجودة؟ من يملكها؟ | إصدار غير محدود بمفتاح واحد |
| صلاحية الترقية (Proxy/Upgradeable) | هل الكود قابل للاستبدال؟ | ترقية منفردة بلا توقيت |
| الملكية (Ownership) | مُتنازل عنها أم لا | مالك يملك سحب سيولة |
| سيولة مقفلة/محروقة | قفل أم حرق؟ ومدة القفل | سيولة مفتوحة بيد المُنشئ |
| الرسوم على النقل (Transfer Tax) | نسبة وتغيّرها | رسوم قابلة للرفع أو حجب البيع (Honeypot) |
| تركّز الحائزين | مؤشر ناكاموتو + معامل جيني | عدد قليل يملك أغلبية العرض |
| قفل المكتسبات (Vesting) | جداول الفتح | فتح ضخم قريب بلا إفصاح |

```
Nakamoto Coefficient = عدد الكيانات اللازمة للتحكم بـ > 50% من العرض/الحصة
Gini = ( 2 Σ i·x_(i) ) / ( n Σ x_(i) ) − (n+1)/n
```
**تحديد السيولة:** سيولة «مقفلة» على منصة قفل هي بدورها **خطر طرف مقابل**: القفل يُدار بعقد/جهة، فالمخاطرة انتقلت لا زالت.

### 7.2 مخاطر الجسر (Bridge)

```
Bridge_Exposure_Risk = قيمة محجوزة × احتمال فشل العقد/الوصاية × (1 − قابلية الاسترداد)
```
**المبدأ:** الجسر يُحوّل مخاطر موزّعة إلى **مخاطرة نقطة واحدة**. لهذا تُحدَّد لكل جسر حد تعرّض مستقل، ويُمنع تجميع تعرّضات جسور مختلفة تحت «سقف واحد» بحجة التنويع إن كانت **مفاتيحها/مدققيها** مترابطة.

### 7.3 السحب الاحتيالي (Rug Pull) — نمط الكشف

تسلسل نمطي: إطلاق رمز → سيولة رقيقة → تسويق → **سحب السيولة** أو بيع حصص المؤسسين. المؤشرات الرقمية:
```
Liquidity/Diluted_Cap < θ      (سيولة ضئيلة نسبة للتقييم → علامة خطر)
Top10_Holders_Share > 50%      (تركّز مفرط)
Liquidity_Locked = false       (وغياب قفل موثّق)
```

|---|---|---|---|
| 1 | اشتق `f*` من الصفر، ثم أثبت `d²g/df² < 0` | الاشتقاق الكامل | اشتقاق بلا مرجع + إثبات القمة |
| 2 | لسيناريو `p = 0.55, b = 1.5` احسب `f*`, `0.5f*`، والنمو المفقود | التقليص | أرقام + نسبة النمو المحتفظ به |
| 3 | احسب `R = (W_b/W_0)^θ` لجزئيتي كيلي 1 و0.5 و0.25، وقارن | حجة نصف كيلي | جدول + استنتاج مكتوب |
| 4 | احسب VaR وES بطريقة معيارية وتاريخية على نفس السلسلة، وقارن | مقارنة الطرق | رقمان لكل طريقة + تفسير الفرق |
| 5 | أثبت بمثال رقمي أن VaR تخالف الجمع الجزئي، وأن ES لا تخالفه | فهم التماسك | مثال صحيح مع أرقام |
| 6 | احسب MaxDD وUI وCalmar وSortino لمسار مُعطى | المقاييس المصحّحة | أربع قيم صحيحة بخطوات |
| 7 | صمّم اختبار ضغط عكسي يخرق حدّ 15% تراجع، واكتب السيناريو | نقطة الانكسار | سيناريو مُعلن + حساب الخرق |
| 8 | طبّق قائمة فحص العقد على رمز على C-Chain واكتب حكماً: مقبول/مرفوض/امتناع | التحقق العملي | كل بند بمصدر + قرار مبرَّر |
| 9 | احسب نسبة مشاركة مركز مقترح في زوج على أفالانش واقترح حجماً يحقق ≤ 5% | التحجيم بالقيود | رقم صحيح + توافق مع كل الحدود |

## معيار إتمام الوحدة 04

1. **الاشتقاق** الكامل لكيلي وتقليصه و`RoR` بلا مرجع مفتوح.
2. **كل التمارين التسعة** مُسلَّمة، وأرقام المخاطر **موسومة «مثال توضيحي»** حيثما لم تكن من مصدر موثّق.
3. **التمييز الصريح** بين VaR وES، وسبب اعتماد ES عند التعارض.
4. **حدود الإيقاف مطبَّقة رقماً:** كل قرار مُقترح يُظهر خسارته القصوى قبل أي حديث عن العائد.
5. **الارتباط في الأزمات** مُستخدَم في حساب التركّز، لا الارتباط الهادئ.
6. **قائمة فحص العقد/الجسر** مطبَّقة على حالة واحدة على الأقل بحكم مكتوب.
7. **عتبة الاجتياز: انظر `exams/README.md §2` (تختلف بحسب الوكيل)** + المرحلة الانضباطية، والامتناع مقبول ومُحتسب عند نقص بيانات الطرف المقابل.
